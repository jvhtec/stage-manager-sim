# Management systems, one at a time

Generated by `npm run balance:ablation` — GB 1995 and ES 1990, seeds 3, 4, 5, 8 years each. The managed company plays the same seed with every system on, then with each one switched off in turn, then with none. Same seed means the same world and the same first offers; after that the runs drift apart, so a difference counts only when it points the same way on every seed.
