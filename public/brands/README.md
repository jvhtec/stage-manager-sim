# Optional official logos (personal builds)

The game draws every brand and company as a typographic badge in its colours.
To use official logos instead, drop the files here and list them in
`index.json`, keyed by the brand/company name in lower-case-hyphen form:

```json
{
  "l-acoustics": "l-acoustics.svg",
  "digico": "digico.png",
  "clair-global": "clair.svg"
}
```

Logos are trademarks of their owners — only add files you're entitled to use,
and keep them out of any public deploy.
